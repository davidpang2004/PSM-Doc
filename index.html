DMS.app 用户手册

DMS 是一款运行在您自己电脑上的文档与照片管理系统。它把您硬盘上的真实文件，组织成一棵可以随意展开、搜索的文件夹树，全部通过浏览器操作，不上传到任何云端服务器。本手册假定您此前从未使用过 DMS，会从"如何安装"开始，逐步讲到每一项功能的具体点击步骤。

01

安装与首次启动

DMS 不需要注册账号，也不需要安装到系统目录——下载后就是一个可以直接双击运行的程序。您的所有文件，从第一步起，就只会保存在您自己指定的硬盘位置上。

1.1 下载

在本页顶部选择您电脑对应的版本下载：Mac 电脑选"Mac 版下载"，Windows 电脑选"Windows 版下载"。下载得到的是一个 .zip 压缩包。

  1. 下载完成后，在"下载"文件夹中找到该 .zip 文件，双击解压。
  2. 解压出的文件夹中会看到 DMS.app（Mac）或 DMS.exe（Windows）。建议把它拖到"应用程序"（Mac）或桌面上您习惯的位置，方便以后打开。

1.2 首次启动

  1. 双击 DMS.app 或 DMS.exe。
  2. 会先弹出一个很小的状态窗口，标题是 "QC Document Management System (QCDMS)"，里面显示当前状态和一个网址链接。不要关闭这个窗口——它就是 DMS 的后台服务，关掉它整个程序就会退出。
  3. 大约一秒后，系统会自动打开您的默认浏览器（推荐 Chrome），显示 DMS 的网页界面。如果没有自动打开，可以点击状态窗口里那行带下划线的网址。
提示 这个小状态窗口右下角有一个 "Quit DMS" 按钮，用来彻底退出程序；左下角的 "Remote Upload" 按钮会在第 13 章"手机与远程访问"中用到，现在可以先不管它。

1.3 设置存储位置

首次启动时，浏览器会显示"设置存储位置"页面，要求您指定一个文件夹，DMS 以后上传的所有 PDF、图片和索引数据都会实实在在地存放在这个文件夹里。

  1. 在"存储路径"输入框中，粘贴或手动输入一个文件夹路径。如果这个文件夹还不存在，DMS 会自动创建它。例如：
    Mac：/Users/yourname/Documents/DMS_Storage
    Windows：C:\Users\yourname\Documents\DMS_Storage
  2. 点击 "保存并继续"。
  3. 系统初始化后会自动进入主界面。
重要提醒 在 Mac 上，请不要把存储路径设置在 iCloud Drive 内部（例如已开启"桌面与文稿同步"的桌面或文稿文件夹）——iCloud 会把不常用的文件自动"云化"、从本地移走，可能导致 DMS 读不到文件。如果想要免费云备份，请改用 OneDrive 或 Dropbox 同步的文件夹（详见第 14 章）。
02

认识主界面

进入主界面后，花两分钟认清下面这几块区域，后面所有章节都会反复用到它们。

2.1 顶部工具栏

  • 中文 / EN 切换按钮 — 点击可随时切换整个应用界面的语言，不影响已保存的数据。
  • 项目 按钮 — 点开是一个下拉菜单，包含导出/导入备份、全局设置、密码保护等，第 14、15、16 章会详细介绍。
  • 当前存储路径按钮 — 显示正在使用的文件夹路径；点击可更改到另一个文件夹（即切换到另一个"项目"）。
  • 如果当前项目设置了项目密码，这里还会显示一个带锁图标的项目名称标签。

2.2 四个标签页

工具栏下方是四个标签页，点击切换：

树形默认视图。左边是文件夹树，右边是选中文件夹里的文档——本手册第 3–5 章主要在这里操作。
搜索关键词搜索，或切换到"AI 问答"整库提问——见第 6、8 章。
数据手册把多份文档合并生成一份带封面的 PDF 手册——见第 11 章。
人脸按人物浏览已标记的照片——见第 10 章。

2.3 树形视图的左右结构

在"树形"标签下：

  • 左侧：文件夹树，可展开/折叠，右键点击任意文件夹弹出操作菜单。树的正上方还有一排快捷按钮：新建文件夹、上传文档、重命名、删除、文本树、趋势图。
  • 右侧：选中文件夹里的文档列表。
03

创建与整理文件夹

文件夹树是 DMS 的骨架，建议先花几分钟按您实际的分类方式（比如按设备、按客户、按家庭成员）搭好大致框架，再往里面添加文档。

3.1 新建文件夹

  1. 在左侧树中，先点击选中一个"父"文件夹（新文件夹会建在它下面）。
  2. 右键点击该文件夹，在弹出菜单中选择 "新建子文件夹"；或者直接点击树上方工具栏里的 "新建文件夹" 按钮。
  3. 输入文件夹名称，按 Enter 确认。

3.2 重命名与删除

  1. 重命名：右键文件夹 →"重命名"，或双击文件夹名称，改好后按 Enter。磁盘上的实际文件夹会同步改名。
  2. 删除：右键文件夹 →"删除文件夹"，确认后该文件夹及其下所有子文件夹和文档都会被删除。
请谨慎操作 删除文件夹会同时删除磁盘上的实际文件，且不经过回收站，无法直接撤销。重要数据建议先按第 14 章导出一份备份，再执行删除。

3.3 拖拽移动、排序与合并

  1. 按住鼠标左键拖动一个文件夹。
  2. 拖到目标文件夹正上方（高亮显示）再松手 → 移动到该文件夹内部，成为其子文件夹。
  3. 拖到目标文件夹的上边缘或下边缘再松手 → 移动为该文件夹的前一个/后一个同级文件夹（仅调整顺序，不改变所属关系）。
自动合并 如果拖入的目标文件夹内已经存在一个同名子文件夹，DMS 会自动把两者合并，源文件夹里的文档和子文件夹会全部并入目标文件夹，不会出现重复的同名文件夹。

3.4 文件夹编号（SN）

可以给每个文件夹设置一个编号（如 A-001），方便与您原有的资产/物料编号体系对应；子文件夹和其中的文档会默认"继承"父文件夹的编号，除非它们自己单独设置了编号。

  1. 在右侧的"文件夹属性"/详情面板中找到"序列号（SN）"字段。
  2. 输入编号并保存。编号会显示在文档卡片上，方便快速识别归属。

3.5 从一份清单批量建立整棵文件夹树

如果您已经有一份文件夹结构的清单（比如项目的资料分类目录），不需要一个个手动新建——可以用缩进文本一次性批量导入。

  1. 点击顶部工具栏的 "项目" → "从层级文件创建文件夹树"。
  2. 在对话框中粘贴层级定义：每行一个文件夹名，用缩进（例如每级 2 个空格）表示层级关系。同一部件名允许在不同的上级下重复出现（例如物料清单里同名的螺栓分别属于不同总成）。
  3. 点击"预览"检查解析结果，确认无误后点击"导入"。
04

添加文档

支持 PDF、JPG、PNG、HEIC、TIFF、GIF、WEBP、BMP 等图片格式，以及 TXT 等文本文件；原则上任何格式的文件都可以上传保存，只是并非所有格式都能在浏览器里直接预览。单个文件最大 4GB。

4.1 拖放上传（最快的方式）

  1. 在左侧树中点击选中目标文件夹。
  2. 直接把文件从桌面或访达/资源管理器窗口，拖到右侧的文档区域。
  3. 松开鼠标，文件自动上传，完成后出现在文档列表中。

4.2 通过按钮上传

  1. 选中目标文件夹后，点击树上方工具栏的 "上传文档" 按钮，或右键文件夹 → "上传文档"。
  2. 在弹出的文件选择对话框中选择文件（可按住 Cmd/Ctrl 多选），点击"打开"。

4.3 从剪贴板直接粘贴截图

不需要先截图保存到桌面再上传：截图后直接在 DMS 页面里按 Cmd+V（Mac）或 Ctrl+V（Windows）即可粘贴进当前文件夹。

4.4 保持文件夹结构整体上传

如果您电脑上已经有一整套按文件夹分类好的资料（比如一个项目的完整目录），上传时可以选择原样保留其子文件夹结构，而不是让 DMS 按日期重新打散归类。

4.5 描述、语音输入与 AI 整理润色

每一份文档和每张照片都可以添加一段自由文字的"描述"，这段文字会被保存进搜索索引，全文可搜索。

  • 语音输入：点击描述框旁边的语音输入按钮，对着电脑说话即可，识别出的文字会自动追加到描述中（Chrome / Edge 浏览器支持效果最佳），打字与口述可以混用。
  • AI 整理润色（需先按第 8 章配置 AI）：口述或随手打的文字往往夹杂口语、错别字或病句，点击 "用 AI 整理润色"，可选择"整理结构""润色文字"或"精简概括"三种方式之一；AI 处理后的结果会先给您预览确认，满意后才会替换原文，不会自动覆盖。
  • 检查错别字：点击 "检查错别字"，AI 会专门检查描述里的错别字、标点和成语误用，逐条列出供您参考修改。
  • 保存方式：写好后点击 "保存并可搜索" 只把这段文字写入索引；如果想把这段描述单独存成一份可以像其他文档一样打开、下载、分享的 .txt 文件，点击 "另存为新文档"（已经存过一次后，这里会变成"更新描述文档"，方便持续修改同一份）。

4.6 照片和视频自动按年月归档

把某个文件夹设为"照片根目录"（第 10 章）后，上传的照片会自动读取拍摄日期，在这个根目录下自动创建"2026"→"08"这样的年/月子文件夹并归入对应位置；如果照片带 GPS 定位信息，拍摄地点也会一并识别出来。iPhone 拍摄的 HEIC 格式照片无需手动转换即可直接预览。

视频文件现在同样会按年月自动归档：MP4、MOV 等格式会直接读取视频文件内部记录的实际拍摄时间；其他视频格式没有这类信息，则改用文件本身的"修改日期"来归档。

4.7 ZIP 批量导入

如果您有大量文档需要上传，并且文件名中已经包含目标文件夹的名称或编号作为前缀（例如 A-001_技术规格书.pdf 对应编号为 A-001 的文件夹），可以打包成一个 ZIP，一次性自动分配。

  1. 点击 "项目" → "从 ZIP 批量导入文档"。
  2. 拖入 ZIP 文件，系统会显示每个文件将被分配到哪个文件夹、哪些未能匹配。
  3. 确认无误后完成导入。

4.8 重复文件

上传时 DMS 会自动检测内容完全相同的文件；如果发现重复，会提示您选择：跳过、把它链接到当前文件夹（不占用额外磁盘空间），或者仍然作为新文件上传。

05

查看、下载与整理文档

5.1 预览文档

  1. 在文档列表中点击一份文档，即可在页面内直接预览：PDF 支持翻页和缩放，还提供"文档内查找"，即使 OCR 文字有一点小错误也能模糊匹配到并跳转高亮；图片按原尺寸显示；文本文件直接显示内容。
  2. 如果想用电脑上安装的其他软件打开（比如用 Word 打开一份 .docx），点击"用原生应用打开"，DMS 会调用系统默认程序。

5.2 重命名与下载

  • 在文档卡片上点击"重命名"，可同时修改磁盘上的文件名和显示名称。
  • 勾选一份或多份文档后点击"下载"，可以把它们复制到您指定的文件夹（默认是系统的"下载"文件夹），完成后能直接打开该文件夹查看。

5.3 把同一份文档关联到多个文件夹

同一份文档可以出现在多个文件夹中，而不会在磁盘上多占一份空间，这称为"链接"。

  1. 打开目标文件夹，点击"链接现有文档"。
  2. 在弹出的窗口中搜索或浏览要链接的文档；也可以直接把结果拖拽到左侧的文件夹上，松手即完成关联，不用再逐个点击确认。
  3. 该文档随即出现在当前文件夹中，同时仍保留在原文件夹里；文档卡片上会显示"已链接至 N 个节点"。
关于删除 删除一个链接只是解除这个文件夹对该文档的引用，不会删除实际文件；只有当所有引用都被删除时，文件才会真正从磁盘上移除（并进入下方的回收区）。

5.4 合并为一份 PDF

可以把选中的多份扫描件或文件快速合并为一个 PDF，合并后的文件会归档到您指定的文件夹里；原始文件仍安全保留、不受影响。快速合并会跳过正式封面页，仅靠每份文档各自的书签导航；即便原始页面是横版，也会自动统一转正为竖版。

5.5 打开一份文档就会一直高亮

打开过的文档（无论是在内置预览里，还是用原生应用打开），会在所在文件夹的列表中持续高亮显示，方便您稍后一眼找回。

5.6 删除文档

点击文档卡片上的删除按钮，确认后：如果该文档被多个文件夹引用，只会解除当前文件夹的引用；如果这是最后一个引用，文件会被移入磁盘上的"Not Show in Tree"回收文件夹（不会立即彻底抹除，可以手动去该文件夹里找回或永久清除）。

5.7 切换视图、排序与批量重命名

  • 列表 / 图标视图：文档区域右上角可以在"列表视图"（详细信息一行一个）和"图标视图"（缩略图网格，类似 Windows 资源管理器）之间切换；图标视图下还能在"小图标"和"大图标"之间切换缩略图大小，方便快速浏览照片，选择会被记住。
  • 排序：文档区域上方的"排序"下拉菜单可按名称（A–Z）、文档日期（元数据）、到期日（元数据）或修改日期排列当前文件夹里的文档。
  • 上一份 / 下一份：预览窗口打开一份文档时，可以点击窗口两侧的箭头，或直接按键盘左右方向键，在当前文件夹的文档之间快速切换，不用每次都关掉预览重新点选。
  • 批量重命名：点击工具栏上的 "批量重命名"，DMS 会为当前文件夹里的每份文档生成一个新文件名——格式为"日期+地点前 10 个字符+原文件名"（例如 20260815旧金山-合同.pdf），日期和地点分别取自文档自身的日期与位置元数据；确认预览列表无误后一次性完成改名，磁盘上的实际文件名也会同步更新。
06

文字识别与搜索

6.1 提取文字（OCR）

对于扫描件或图片（没有文字层，无法直接选中复制的那种 PDF/图片），DMS 可以自动识别出其中的文字，识别后的文字既能被搜索到，也能用来自动填写关键参数。

  1. 打开一份文档的预览。
  2. 点击 "提取文字 (OCR)"。如果文档本身带有可选中的文字层，系统会直接读取；如果是纯图片或扫描件，则会调用 OCR 引擎识别。
  3. 识别完成后，文字会显示出来，可以手动修改纠错，再点击保存。
扫描件文字有误？ 如果 PDF 本身带了一层内容错误的文字（常见于某些扫描软件生成的文件），可以点击 "强制 OCR"，让 DMS 忽略原有文字层，直接对页面图像重新识别一遍。

6.2 关键词搜索

  1. 切换到顶部"搜索"标签页（或树形视图右上角的搜索框）。
  2. 输入编号、文件名、描述文字或元数据关键词，结果会实时过滤显示。

搜索范围包括文件名、OCR 识别出的全文，以及您为文档添加的所有元数据字段（见第 7 章）。系统还会自动标记出可能不可靠的乱码 OCR 结果，避免它们干扰搜索。

07

关键参数：从文档中提取结构化数据

"关键参数"是您给每份文档附加的自定义信息字段，例如"甲方""签署日期""金额""工作压力"。填好之后，这些信息既可以在搜索里用到，也能变成第 9 章"趋势图表"里的数据点。对完全没概念的用户，可以把它简单理解成"给每份文档打一些自定义标签，并写上对应的值"。

7.1 管理全局字段列表

系统预设了一些常用字段名，您可以按需增删，设置好后，之后给任意文档添加字段时，输入框会自动弹出这些名称供选择，保持命名统一。

  1. 点击 "项目" → "全局关键参数"。
  2. 点击"添加"输入新字段名；点击字段旁边的删除图标可移除；可拖动调整顺序。
  3. 点击"保存"，全局参数列表立即生效。

7.2 给一份文档添加参数值

  1. 打开一份文档，找到"元数据"/关键参数区域，点击展开。
  2. 点击"添加字段"，从下拉列表选一个已有字段名（或直接输入一个只属于这份文档、不进入全局列表的新字段名）。
  3. 在字段右侧填入具体的值，点击保存，即时写入。

7.3 设计值与实测值

每个参数都可以同时保存"设计值"和"实测值"两组数据，各自包含数值、单位、说明三部分，适合需要核对设计要求与现场实测结果是否一致的场景（比如设备验收）。

7.4 自动从文档文字中提取

如果文档已经完成第 6 章的文字识别，就可以让 DMS 自动在文字里查找关键词并抓取对应数值，不用逐字手动录入。

  1. 在文字识别面板中点击 "提取关键参数"。
  2. 勾选需要提取的字段名。
  3. 点击 "开始提取"，系统会在全文中查找字段关键词及其后面的数值。
  4. 预览提取结果——每条结果会自动拆分为数值、单位、说明三部分，而不是一整段原始文字；同一字段在文档里出现多次时，会分别编号（如"压力_01""压力_02"）单独列出，不会遗漏。
  5. 确认无误后点击"应用到文档"。
表格类文档小技巧 勾选"仅同行提取"，DMS 只会匹配与字段名处在同一行的内容，更适合表格；不勾选则在全文范围内搜索。

7.5 核对时的浮窗预览

人工录入或核对参数时，可以弹出一个可拖拽、可自由缩放的原文档预览小窗口，一边看着原文一边填写，不需要来回切换页面。

7.6 把所有元数据导出成表格

点击 "项目" → "导出元数据 (CSV)"，即可把库里每一份文档及其全部关键参数导出成一张电子表格，直接用 Excel 打开查阅或做进一步分析。

08

AI 辅助（可选功能）

这一整章的功能都是可选的：不配置也完全不影响其他所有功能的正常使用。它需要您自己申请一个免费或低价的 AI 服务密钥（API Key），并保持联网。DMS 现在支持两种 AI 服务：Google 的 Gemini 和 DeepSeek（国内用户访问更快更稳定），二选一或都配置、随时切换均可。

8.1 申请并配置密钥

  1. 点击 "项目" → "AI 辅助提取设置"，打开"AI 提供商设置"对话框。
  2. Gemini：点击"没有 API Key？前往 Google AI Studio 免费获取"，网址是 aistudio.google.com/apikey；按页面提示登录 Google 账号并创建密钥，复制后粘贴回 DMS 的输入框。
  3. DeepSeek：点击"没有 API Key？前往 DeepSeek 开放平台获取"，同样登录、创建、复制、粘贴。
  4. 保存后密钥会被加密保存在本地，不会以明文形式存储。
费用说明 Gemini 免费额度每次最多处理 3 页文档，对大多数体检报告、产品测试报告已经足够；需要处理几十甚至上百页的大型文档，可订阅 Gemini 付费版（约 10 美元/月）。Gemini 付费版还承诺不会把您上传的文件用于训练其模型，更适合涉及隐私或商业敏感信息的文档。

8.2 AI 辅助提取关键参数

对于版式复杂、普通文字匹配抓不准的文档（比如参数散落在图表或复杂表格里），可以让 AI 直接"看"文档页面的图像来提取数值，而不是只匹配文字。在第 7.4 节的提取面板中，勾选"使用 AI"再开始提取即可。

8.3 就整个项目提问（Ask AI）

  1. 切换到顶部"搜索"标签页，点击 "AI 问答"。
  2. 在输入框中用一句话提问，例如"设备的工作压力是多少？"
  3. 选择使用 Gemini 还是 DeepSeek，点击提问。AI 会自动跨文档查找答案，并标注具体来自哪一份文档，方便您核实原文。

也可以只把范围限定在某一个文件夹（勾选"仅限此节点及子节点"），而不是整个项目。

8.4 问答记录自动保存

每次向 AI 提问，问题和回答都会自动追加进一份与该文档关联的 PDF 记录里，随时可以在文档列表中打开查阅、也能被搜索到，不需要自己另外整理。

8.5 打包成 PDF，交给 ChatGPT 等其他 AI 工具

DMS 自带的"AI 问答"（8.3 节）适合快速查资料，但如果您想用照片和文字讲一个故事，让 AI 生成一段视频、一篇文章或其他 DMS 本身不提供的创作，可以改用"生成 PDF"，把素材打包好交给 ChatGPT 等支持文件上传、具备图像理解能力的 AI 工具去完成。

  1. 在"对文件夹提问 AI"对话框中（第 8.3 节同一入口），勾选要用到的照片或文档。
  2. 在提问框里写下您对 AI 的要求（例如"根据这些照片和故事生成一段视频，配轻音乐"），也可以用语音输入并请 AI 整理润色（见 4.5 节）。
  3. 点击 "生成 PDF（供 ChatGPT 等）"，DMS 会把选中的照片压缩转换为体积很小但清晰度不打折的 PDF 页面，连同您的文字要求一起合并成一份 PDF 并下载下来。
  4. 把下载好的 PDF 上传到 ChatGPT 或其他 AI 工具，照常提出您的请求即可。因为照片已经转换为体积很小的 PDF，即便选了很多张照片，上传和处理也会顺畅很多。
和第 8.3 节的区别 8.3 节的"直接问 AI"由 DMS 内置调用 Gemini/DeepSeek 直接给出文字回答；这里的"生成 PDF"则是把素材打包好，交给您自己选择的、能力更强或更适合创作类任务的外部 AI 工具去处理，DMS 本身并不生成视频或其他创作内容。
09

趋势图表

如果某个关键参数（比如"胆固醇""账户余额""工作压力"）会在同一个文件夹下的多份文档里反复出现，DMS 可以把它们按日期自动画成一张趋势图，不需要另外导出到 Excel 里手工画图。

9.1 生成一张趋势图

  1. 在左侧树中选中要分析的文件夹。
  2. 点击树上方工具栏的 "趋势图" 按钮。
  3. 选择要观察的关键参数字段，并选择是否包含该文件夹下的所有子文件夹。
  4. 系统自动把每份文档里这个参数的数值，按日期绘制成折线图。日期优先取自文档自身识别或录入的日期；如果文档没有日期，就退而使用它所在的"YYYY-MM"文件夹名。

点击图上的任意一个点，或下方数据表格中的一行，都可以直接跳转打开对应的源文档，方便核实这个数字究竟来自哪里。

9.2 调整图表窗口

  • 拖动图表窗口的标题栏可以移动位置，拖动边框或四角可以缩放大小。
  • 点击"弹出"按钮，可以把图表打开成一个独立的浏览器窗口，方便挪到另一台显示器上单独查看。
  • 横轴（时间）和纵轴（数值）都可以在"自动"和"自定义"范围之间切换；切换到自定义时会先带入当前自动计算出的范围，之后随您编辑实时更新。

9.3 年化收益率（适合追踪账户余额、投资回报）

点选图上任意一个点作为"基准点"，即可查看其余各点相对这个基准点的年化收益率；也可以查看相邻两点之间的链式年化收益率。这在追踪账户余额、投资组合等财务类数据时特别有用。

9.4 Excel 快照历史（适合手动记录的累计数据）

有些数据（比如银行账户总余额）并不来自某一份具体文档，而是您需要定期手动记录的一个总数。这时可以用"快照"功能：

  1. 在趋势图窗口中点击 "保存快照"，把今天的日期和当前数值追加进一份按文件夹、按参数保存的 Excel 历史表中。
  2. 切换到"总额-时间"视图，即可直接读取这份历史表画出趋势图，无需从任何单一文档中提取数据。

9.5 AI 趋势点评（可选）

如果已按第 8 章配置好 AI 服务，可以点击开启 AI 点评，对趋势方向、大致变化速率，以及任何值得关注的异常值给出一段简明分析。

10

照片库与人脸识别

10.1 设置照片根目录

先指定一个文件夹作为照片库的根节点，之后所有自动整理的照片都会归入它的子文件夹中。

  1. 右键点击要作为根节点的文件夹（例如新建一个叫"照片库"的文件夹）。
  2. 选择 "设为照片根目录"。
  3. 该文件夹图标会变成相机图标，表示设置成功。若要取消，右键选择"取消照片根目录"。
注意 每个项目只能设置一个照片根节点。

10.2 上传照片

上传照片到照片根目录（或其子文件夹）时，DMS 会自动读取照片的拍摄日期（EXIF 信息），在根目录下创建对应的"年/月"子文件夹并归入；如果照片带 GPS 信息，拍摄地点也会一并识别，显示为文档元数据中的"Location"字段，并可一键在地图上查看拍摄地点。

10.3 标记人脸

  1. 选中一张或多张照片。
  2. 点击"标记人脸"，在照片中框选出人物，输入姓名（首次标记某人时会新建一个"人物"条目，此后重复使用同一个名字即可归入同一人）。

10.4 按人物浏览照片

  1. 切换到顶部 "人脸" 标签页。
  2. 点击任意一个已标记的人物，即可看到这个人在整个库中出现过的所有照片。
  3. 点击"自动扫描匹配"，可以在某个文件夹或整个库范围内查找这位（或所有已标记）人物可能出现的更多照片，匹配的置信度阈值可以调整。

如果需要删除某个人物，可以一键删除该人物及其全部标记，不会影响照片本身。首次使用人脸识别功能前，系统会引导您安装底层识别引擎，并实时显示安装进度。

10.5 查找相似照片，清理重复内容

连续拍摄、反复保存或多次导出，常常会在同一批照片里留下好几张几乎一样的重复照片。DMS 可以自动挑出这些"近似重复"的照片，并推荐保留其中最好的一张。

  1. 打开一个装着照片的文件夹，点击工具栏上 "多选" 旁边的 "查找相似照片" 按钮，进入照片选择模式。
  2. 勾选想要比较的几张照片（只能勾选图片文件），设置右侧的 "相似度阈值"（默认为 75%，可自行调整，数值越高判定越严格）。
  3. 点击 "检测相似照片"，DMS 会在这批照片之间两两比较，把相似度达到阈值的照片自动归为一组，并标出每组的最低相似度。
  4. 每组照片中，DMS 会用一枚 ★ 星标 推荐其中分辨率最高、文件体积最大（即压缩最少、质量通常最好）的一张作为"建议保留"的版本，供您参考——最终留哪张仍由您自己判断。
  5. 确认无误后点击 "标记以便审查"，DMS 会把每一组照片链接（而非移动）到根目录下新建的 "疑似重复照片" 文件夹中对应的"组N"子文件夹里，原照片仍留在原来的文件夹中，方便您稍后统一查看、比对、删除。
缩略图大小 在结果窗口和正常的"图标视图"里，都可以在"小图标"和"大图标"之间切换，方便仔细比对照片细节；该设置会被记住，下次打开自动沿用（见 5.7 节）。
在"疑似重复照片"文件夹里删除，才是真正的清理 这个文件夹里的照片只是"链接"过来的，原照片仍保留在其原始文件夹中——按 5.6 节的一般规则，在别处删除通常只会解除当前文件夹的引用。但如果直接在"疑似重复照片 / 组N"里点删除，DMS 会把这份照片从它所有的位置一并移除（包括原始文件夹），并移入"Not Show in Tree"回收文件夹，这样才能真正达到清理重复照片、释放空间的目的。

生成数据手册（合并 PDF 手册）

"数据手册"功能可以把文件夹树里任意选中的一批文档，一键合并成一份带封面、目录和分节书签的正式 PDF 手册，非常适合作为交付资料或存档打印。

  1. 切换到顶部 "数据手册" 标签页。
  2. 在文档选择器中勾选要合并的文档，可以跨多个文件夹选择。
  3. 填写手册的标题和副标题（如需要，可以在自动生成的封面之前再插入一张自定义封面）。
  4. 点击 "生成并下载"，系统会把所有选中文档按文件夹顺序、序列号自动排列成章节结构，合并成一份 PDF。
  • 只包含图片的文件夹会自动转换为可打印的 PDF 页面。
  • 横版的原始页面会自动旋转为竖版，保证整本手册方向统一。
  • 含大量照片时，图片会在嵌入前智能重新压缩，页面观感几乎无损，但整份文件体积可以缩小到原来的百分之一左右。
提示 已经生成过一次的选择列表和标题会自动记住，下次打开"数据手册"标签页时可以直接在上次的基础上继续操作。

分享文档

12.1 通过邮件发送

需要先配置一次 SMTP 邮箱设置（Mac 和 Windows 都适用）：

  1. 点击 "项目" → "邮件发送设置"。
  2. 点击顶部对应邮箱服务商的快捷按钮（Gmail / Yahoo / Outlook / iCloud / QQ 邮箱 / 网易163），自动填入服务器地址和端口。
  3. 填写用户名（您的邮箱地址）和密码。Gmail 用户请使用"应用专用密码"，不是账户登录密码——需要单独在 Google 账号设置里生成。
  4. 点击"发送测试邮件"验证设置，成功后您的邮箱会收到一封测试邮件；确认无误后点击"保存设置"。

设置好之后，发送文档时：

  1. 在文档卡片上点击邮件图标。
  2. 填写收件人地址（系统会记住上次填写过的地址）、主题（默认是文档名称）和正文（可选）。
  3. 点击"发送邮件"，系统通过 SMTP 直接发送，片刻后收件人即可收到。
未配置 SMTP 时 在 Mac 上会自动改用"信息"或 Mail App 帮您打开一封草稿；在 Windows 上则必须先完成上面的 SMTP 配置才能发送邮件。

12.2 发送到手机

点击文档卡片上的手机图标，输入对方手机号码，点击发送。系统会生成一个有效期 1 小时的下载链接，通过 Mac 的"信息"App（iMessage/短信）或 Windows 的"你的手机"应用发送过去，对方无需安装任何 DMS 相关的 App，点开链接即可下载。

手机与远程访问

这一章介绍反过来的方向——用手机往电脑里传照片/文件，或者用手机直接浏览电脑上的整棵文件夹树。这两项功能都是从启动时弹出的那个小状态窗口（第 1.2 节提到的 "QCDMS" 窗口）里操作的，而不是在浏览器网页里。

13.1 从手机上传照片或文件到某个文件夹

  1. 在电脑上找到那个小状态窗口（如果被最小化了，可以在任务栏/程序坞里找回），点击 "Remote Upload" 按钮。
  2. 在弹出的对话框中，可选填入手机号码（含国家代码，如 +8613800138000），并从下拉列表中选择希望文件传到哪个文件夹。
  3. 点击 "Generate Link"，系统会启动一条安全的公网隧道并生成一个二维码和链接（此过程通常需要几秒到十几秒）。
  4. 用手机扫描二维码，或点击"Send via iMessage / SMS / WeChat"直接把链接发到手机上，也可以点"Copy URL"手动复制发送。
  5. 手机上打开链接后，即可拍照或从相册中选图直接上传，文件会自动出现在您第 2 步选择的那个文件夹里。
链接有效期 这个远程上传链接有效期为 7 天，过期后需要重新点击一次"Generate Link"生成新的。

13.2 在手机上浏览电脑里的文件

用手机打开第 13.1 节生成的同一条链接后，页面上会有一个"浏览"入口，点进去即可像在电脑上一样浏览整棵文件夹树、打开文档查看，而不仅仅是上传新文件。

13.3 同一 Wi-Fi 下的局域网访问

如果手机和电脑连接的是同一个 Wi-Fi 网络，也可以不经过公网隧道，直接在手机浏览器里访问电脑的局域网地址（形如 http://192.168.x.x:端口号/mobile）打开同样的上传页面。如果不确定电脑的局域网地址，最简单的方式仍是使用上面 13.1 节的 "Remote Upload"，它在任何网络环境下都能用。

14

备份、导出与导入

DMS 里的一切都是普通文件，不会被"锁死"在专有格式里。点击顶部 "项目" 按钮即可看到全部备份/导出选项。

14.1 三种导出方式

导出索引备份（.dms）只保存文件夹树结构和元数据，不含实体文件，文件名以 METADATA- 开头，体积很小，适合快速留存结构。
导出完整备份（含文件）把文件夹树、元数据和全部实体文档、照片一起打包，文件名以 COMP- 开头，是最完整的一份备份。
导出选定文件夹（含文件）先勾选部分文件夹，只导出这些文件夹树及其中的文件，文件名以 PART- 开头，适合只想分享/备份某一部分内容的场景。

另外还有 "导出元数据 (CSV)"——把所有文档的元数据导出成表格，方便在 Excel 中查阅或记账。

自动保留最近 10 份 导出的 .dms 备份文件会保存在存储文件夹内。项目目录中最多保留 10 个 .dms 备份文件，更早的会自动移入"Not Shown in The Tree"文件夹，不会无限占用空间。
已设项目密码时 如果当前项目设置了项目密码（见第 15.2 节），以上每一种导出都会自动用这个密码加密，不需要另外再单独设置导出密码。

14.2 导入一份 .dms 备份

  1. 点击 "项目" → "导入项目（.dms）"，或者直接把 .dms 文件拖到上传区域。
  2. 选择一个目标文件夹作为解压位置。
  3. 确认后系统开始解压并导入，完成后自动切换到这个新导入的项目。

导入只会恢复文件夹树结构，不会删除磁盘上任何已有的文件。

14.3 新建一个全新的空白项目

点击 "项目" → "新建空白项目"，输入一个新的空文件夹路径即可，当前正在使用的项目不受影响，随时可以通过顶部的存储路径按钮切回来。

14.4 免费云备份

只要把存储路径设置在一个已经开启同步的 OneDrive 或 Dropbox 文件夹里，DMS 的所有数据就会随文件夹自动同步备份到云端，不需要额外操作。应用内提供分步的 OneDrive 配置指南（在"项目"菜单的"文档下载"区域可以下载）。

再次提醒 Mac 上请不要把存储路径放进 iCloud Drive（详见第 1.3 节的说明）。
15

安全与密码保护

DMS 提供两层完全独立的密码保护，可以只用一层，也可以两层都用。

15.1 应用登录密码（保护整台电脑上的 DMS）

这是一个可选的登录密码，保护本机上的整个 DMS 应用，不管当前打开的是哪个项目——适合公用电脑或希望别人完全无法打开 DMS 的场景。

  1. 点击 "项目" → "设置应用登录密码"。
  2. 输入新密码（两次确认），点击保存，立即生效。之后每次打开浏览器访问 DMS 都需要先输入这个密码。
  3. 如需修改或移除，回到同一入口（此时会显示为"修改或移除应用登录密码"），输入当前密码验证身份后操作；移除时把新密码留空即可。
  4. 已设置密码时，菜单里会出现"退出登录"选项，点击后当前浏览器会话结束，下次访问需要重新输入密码。
存储方式 密码以加密形式（SHA256 加随机盐、10 万次迭代）存储在本机的配置文件中，不会以明文保存。

15.2 项目密码（只保护某一个具体项目）

这是与上面完全独立的第二重密码，只属于某一个具体的项目——密码信息就存储在这个项目的文件夹内部，会随着文件夹一起被复制、同步或交给别人。打开这个项目、或者在别的电脑上导入它导出的 .dms 备份时，都需要这个密码。

  1. 点击 "项目" → "设置项目密码"。
  2. 可以给这个项目起一个便于识别的名称（会显示在锁定界面和文件选择器中），设置密码后保存。
  3. 已设置密码时，工具栏会出现带锁图标的项目名称标签；菜单里出现"锁定当前项目"选项，点击后需要重新输入项目密码才能继续查看（不影响上面的应用登录状态）。

15.3 按文件夹保存网站登录信息

可以在某个文件夹下保存一组或多组相关的网站地址、用户名和密码（例如某台设备厂家管理后台的登录信息），只有点击"显示"时才会解密显示；同一个文件夹下现在可以保存任意多组这样的登录信息，并提供"复制用户名"的快捷按钮。

常见问题

忘记了应用登录密码怎么办？
可以手动编辑本机的配置文件重置密码。文件位于 Mac 的 ~/.pms_dms_config.json 或 Windows 的 C:\Users\yourname\.pms_dms_config.json。用文本编辑器打开，把其中 password_hash 和 password_salt 两个字段的值都改成空字符串 ""，保存后重启 DMS，密码保护即被移除。（这是应用登录密码，与第 15.2 节的"项目密码"是两回事，项目密码保存在项目文件夹内，同理可用文本编辑器打开项目文件夹里的相应配置文件清空重置。）
误删了文件夹或文档，能恢复吗？
删除文档时，只要它还被其他文件夹引用，就只是解除引用，文件本身还在；只有最后一个引用被删除，文件才会移入磁盘上的"Not Show in Tree"文件夹，可以手动去那里找回。但整个文件夹的删除是不可逆的，建议重要操作前先按第 14 章导出一份备份。如果存储路径本身开启了云盘同步（如 OneDrive），也可以尝试通过云盘的版本历史找回。
为什么发邮件提示"SMTP 错误"？
常见原因：Gmail 未使用"应用专用密码"（用的是账户登录密码）；服务商的 SMTP 服务未开启（QQ、163 邮箱需要先在网页版里手动开启）；公司网络防火墙屏蔽了 587 或 465 端口，需联系网络管理员。
文档可以在多台电脑上共享使用吗？
可以。把存储路径设置到一个共享网络磁盘，或云同步文件夹（如 OneDrive、Dropbox；Mac 上请避开 iCloud Drive，见第 1.3 节），多台电脑上的 DMS 都指向同一路径即可共享数据。但请注意不要在两台电脑上同时编辑同一份文档，以免产生冲突，建议按文件夹分工使用。
Windows 上双击 DMS.exe 提示"Windows 已保护你的电脑"（SmartScreen 警告）怎么办？
这是因为 DMS.exe 是新生成的可执行文件，还没有向微软付费购买"数字签名认证"，Windows 默认会拦截未知来源的新程序以保护用户，这不代表程序有问题。两种处理方式：

方法一（推荐，最简单）：在警告窗口中点击"更多信息"链接，窗口底部会出现一个"仍要运行"按钮，点击它即可正常启动。

方法二：如果窗口已经关闭或无法点击，可以右键点击 DMS.exe → "属性" → 在"常规"选项卡最下方勾选"解除锁定"复选框 → 点击"应用" → "确定"。这样设置后以后也不会再触发 SmartScreen 警告。
支持哪些文件格式？
支持 PDF、JPG、JPEG、PNG、HEIC、TIFF、GIF、WEBP、BMP（图片格式），以及 TXT、CSV 等文本文件。原则上任何格式的文件都可以上传并保存，但页面内直接预览功能仅支持以上列出的格式，其他格式可以下载后用对应软件打开。
DMS.app 和 DMS.exe 有什么区别？只是分别对应 Mac 和 Windows 吗？
是的，两者功能完全相同，分别是打包给 Mac 和 Windows 用户的可执行程序，双击即可运行，不需要额外安装 Python 或任何依赖库。

Install & First Launch

DMS needs no account and no system-level install — download it and you have a program you can double-click straight away. From the very first step, every file you add lives only on the hard drive location you choose yourself.

1.1 Download

Use the button at the top of this page for your computer: "Download for Mac" or "Download for Windows". You'll get a .zip archive.

  1. Once downloaded, find the .zip in your Downloads folder and double-click to unzip it.
  2. Inside you'll find DMS.app (Mac) or DMS.exe (Windows). Drag it into Applications (Mac) or wherever you'll remember on your Desktop, so it's easy to find later.

1.2 First launch

  1. Double-click DMS.app or DMS.exe.
  2. A small status window titled "QC Document Management System (QCDMS)" appears first, showing status and a URL link. Don't close this window — it's DMS's background server; closing it quits the whole program.
  3. After about a second, your default browser (Chrome recommended) opens automatically to the DMS web interface. If it doesn't, click the underlined URL in the status window.
Tip That small status window has a "Quit DMS" button (bottom-right) to fully exit the program, and a "Remote Upload" button (bottom-left) used in Chapter 13, "Mobile & Remote Access" — you can ignore it for now.

1.3 Set your storage location

On first launch, the browser shows a "Set storage location" page asking you to pick one folder — every PDF, image, and index DMS ever saves will physically live inside it.

  1. In the "Storage path" field, paste or type a folder path. If it doesn't exist yet, DMS creates it automatically. For example:
    Mac: /Users/yourname/Documents/DMS_Storage
    Windows: C:\Users\yourname\Documents\DMS_Storage
  2. Click "Save and continue".
  3. The app initializes and takes you straight to the main screen.
Important On Mac, do not pick a folder inside iCloud Drive (e.g. a Desktop or Documents folder with "Desktop & Documents sync" turned on) — iCloud can silently move infrequently-used files off your local disk, which can make DMS unable to read them. For free cloud backup, use a OneDrive- or Dropbox-synced folder instead (see Chapter 14).

03

Building Your Folder Tree

The folder tree is DMS's backbone. It's worth spending a few minutes sketching out the rough structure that matches how you actually think about your files (by equipment, by client, by family member) before adding documents.

3.1 Create a folder

  1. In the left tree, click to select a "parent" folder (the new folder will be created inside it).
  2. Right-click that folder and choose "New subfolder", or click the "New folder" button in the toolbar above the tree.
  3. Type a name and press Enter.

3.2 Rename & delete

  1. Rename: right-click a folder → "Rename", or double-click its name, edit, and press Enter. The real folder on disk is renamed to match.
  2. Delete: right-click a folder → "Delete folder" and confirm — the folder and everything under it (subfolders and documents) is removed.
Be careful Deleting a folder deletes the real files on disk too, and doesn't go through a recycle bin — it can't be undone directly. For anything important, export a backup first (Chapter 14) before deleting.

3.3 Drag to move, reorder, or merge

  1. Press and hold the left mouse button on a folder to drag it.
  2. Drop it directly on top of another folder (it highlights) → moves it inside that folder, becoming a subfolder of it.
  3. Drop it on the top or bottom edge of another folder → moves it to become that folder's previous/next sibling (reorders only, doesn't change parents).
Automatic merging If the target folder already has a subfolder with the exact same name, DMS automatically merges the two — every document and subfolder from the source is folded into the target, so you never end up with duplicate same-named folders.

3.4 Folder serial number (SN)

Each folder can carry a serial number (e.g. A-001) to match your existing asset or part numbering. Subfolders and their documents default to "inheriting" their parent's SN unless they set their own.

  1. In the folder details panel on the right, find the "Serial number (SN)" field.
  2. Type the number and save. It appears on document cards so you can identify what they belong to at a glance.

3.5 Bulk-build a whole tree from a list

If you already have a written-out folder structure (e.g. a project's filing categories), you don't have to create each folder by hand — paste an indented outline and import it all at once.

  1. Click "Project" → "Create folder tree from a hierarchy file" in the top toolbar.
  2. Paste your hierarchy definition into the dialog: one folder name per line, with indentation (e.g. 2 spaces per level) showing nesting. The same part name is allowed to repeat legitimately under different parents (like a bill-of-materials).
  3. Click "Preview" to check the parsed result, then "Import" once it looks right.
04

Getting Documents In

Supported image formats include PDF, JPG, PNG, HEIC, TIFF, GIF, WEBP, and BMP, plus text files like TXT. In principle any file type can be uploaded and stored, though not every format can be previewed directly in the browser. Maximum size per file is 4GB.

4.1 Drag and drop (the fastest way)

  1. Click to select the target folder in the left tree.
  2. Drag files straight from the Desktop or a Finder/Explorer window onto the document area on the right.
  3. Release — the file uploads automatically and appears in the document list.

4.2 Upload via the button

  1. With a folder selected, click "Upload document" in the toolbar above the tree, or right-click the folder → "Upload document".
  2. In the file picker, select files (hold Cmd/Ctrl to multi-select) and click "Open".

4.3 Paste a screenshot straight from the clipboard

No need to save a screenshot to the Desktop first — take the screenshot, then press Cmd+V (Mac) or Ctrl+V (Windows) anywhere on the DMS page to drop it straight into the current folder.

4.4 Upload while keeping an existing folder structure

If you already have a whole set of material organized into folders on your computer (e.g. a project's full directory), you can choose to recreate that exact subfolder layout inside DMS instead of letting it auto-sort everything by date.

4.5 Descriptions, voice input & AI polish

Every document and photo can carry a free-text "description" — it's saved into the search index and fully searchable.

  • Voice input: click the voice-input button next to the description box and just speak — the transcribed text is appended automatically (works best in Chrome/Edge), and you can freely mix typing and dictation.
  • AI organize & polish (needs AI configured, Chapter 8): dictated or quickly-typed text often comes out rough — click "Organize & polish" and pick one of "Organize", "Polish wording", or "Make concise". The AI's result is shown for you to review first; it only replaces your original text once you accept it.
  • Check typos: click "Check typos" to have AI specifically flag typos, punctuation issues, and misused idioms in the description, listed one by one for you to fix.
  • Saving: click "Save and make searchable" to store the text in the index only; to also save this description as its own standalone .txt document you can open, download, or share like any other file, click "Save as new document" (once saved, this becomes "Update description file" so you can keep revising the same one).

4.6 Photos and videos auto-filed by year and month

Once a folder is set as the "photo root" (Chapter 10), uploaded photos automatically read their capture date and get filed into "2026" → "08"-style year/month subfolders under it. If a photo carries GPS data, the shooting location is picked up too. HEIC photos from an iPhone preview correctly with no manual conversion.

Videos are now filed the same way: MP4/MOV-family files use the recording timestamp embedded in the video itself, while other video formats fall back to the file's own modified date.

4.7 Bulk import from a ZIP

If you have a large batch of documents whose filenames already start with the name or number of their target folder (e.g. A-001_spec-sheet.pdf for the folder numbered A-001), you can zip them up and let DMS sort them all at once.

  1. Click "Project" → "Bulk import documents from ZIP".
  2. Drop in the ZIP file — DMS shows which files match which folder, and which couldn't be matched.
  3. Confirm to finish the import.

4.8 Duplicate files

On upload, DMS automatically checks for files with identical content already in the library. If it finds a match, it asks whether to skip, link the existing file into this folder instead (no extra disk space used), or upload it anyway as a new file.

05

Viewing, Downloading & Organizing Documents

5.1 Previewing a document

  1. Click any document in the list to preview it right on the page: PDFs support page navigation and zoom, plus a "find in document" search that tolerates small OCR typos and jumps straight to the highlighted match; images show at full size; text files display their content directly.
  2. To open it in another app installed on your computer instead (e.g. Word for a .docx), click "Open in native app" and DMS hands it to your system's default program.

5.2 Rename & download

  • Click "Rename" on a document's card to change both the file on disk and its display name at once.
  • Select one or more documents and click "Download" to copy them to a folder of your choice (the system Downloads folder by default), with the option to open that folder right away.

5.3 Linking one document into several folders

The same document can appear in multiple folders without using extra disk space — this is called "linking".

  1. Open the target folder and click "Link existing document".
  2. Search or browse for the document in the dialog that opens; you can also drag a result straight onto a folder on the left to link it in one motion, with no per-item confirm click needed.
  3. The document now appears in the current folder while still remaining in its original one; its card shows "Linked to N node(s)".
About deleting a link Removing a link only detaches that one folder's reference to the document — it doesn't delete the actual file. Only once every reference is removed does the file actually move off disk (into the recycle area below).

5.4 Combine into one PDF

Merge several selected scans or files into a single PDF, filed back into a folder you choose; the originals stay untouched in storage. Quick merges skip the formal cover page — per-document bookmarks alone handle navigation — and any landscape page is automatically rotated to portrait so the whole file stays consistently oriented.

5.5 Opening a document keeps it highlighted

Any document you've opened (in the built-in preview or a native app) stays highlighted in its folder's list, so you can spot it again at a glance later.

5.6 Deleting a document

Click the delete button on a document's card and confirm. If the document is linked into other folders, only the current folder's reference is removed; if this was its last reference, the file is moved into the "Not Show in Tree" recycle folder on disk (not immediately erased — you can find or permanently clear it there manually).

5.7 View mode, sorting & batch rename

  • List / icon view: toggle between "List view" (one detailed row per document) and "Icon view" (a thumbnail grid, like Windows Explorer) at the top right of the document area; in icon view, a further "Small"/"Large" toggle controls thumbnail size — handy for browsing photos quickly, and your choice is remembered.
  • Sorting: the "Sort by" dropdown above the document list orders the current folder's documents by name (A–Z), document date (metadata), due date (metadata), or date modified.
  • Previous / next: with a document open in the preview window, click the arrows on either side of it, or just press the left/right arrow keys, to step through the current folder's documents without closing and reopening the preview each time.
  • Batch rename: click "Batch rename" in the toolbar to generate a new filename for every document in the current folder — in the form "date + first 10 characters of location + original name" (e.g. 20260815SanFrancisco-contract.pdf), using each document's own date and location metadata. Review the preview list, confirm, and every file is renamed at once — including the actual file on disk.
06

OCR & Search

6.1 Extracting text (OCR)

For a scan or an image with no selectable text layer, DMS can recognize the text inside it. Once recognized, that text becomes searchable and can also auto-fill key parameters.

  1. Open a document's preview.
  2. Click "Extract text (OCR)". If the document already has a selectable text layer, DMS reads it directly; for a pure image or scan, it runs the OCR engine.
  3. Once recognized, the text appears and can be hand-corrected before saving.
Scan has a bad text layer? If a PDF already has a text layer but it's wrong (common with certain scanning software), click "Force OCR" to ignore the existing layer and re-recognize the page image from scratch.

6.2 Keyword search

  1. Switch to the top "Search" tab (or use the search box in the top-right of the Tree view).
  2. Type a number, filename, description, or metadata keyword — results filter live as you type.

Search covers filenames, the full text from OCR, and every metadata field you've added to a document (Chapter 7). DMS also flags likely-unreliable garbled OCR output so it doesn't pollute your search results.

07

Key Parameters — Extracting Structured Data

"Key parameters" are custom information fields you attach to a document — things like "Client", "Signed Date", "Amount", or "Working Pressure". Once filled in, this data is searchable, and can also become the data points behind Chapter 9's trend charts. If none of this is familiar yet, think of it simply as tagging each document with your own custom labels and values.

7.1 Managing the global field list

DMS ships with a few common field names already set up; you can add or remove your own. Once set, any field you start typing on a document will suggest these names, keeping naming consistent.

  1. Click "Project" → "Global key parameters".
  2. Click "Add" to type a new field name; click the ✕ next to a field to remove it; drag to reorder.
  3. Click "Save" — the global list takes effect immediately.

7.2 Adding a value to one document

  1. Open a document and expand its metadata / key-parameters area.
  2. Click "Add field" and pick an existing name from the dropdown (or type a new one that belongs only to this document, without joining the global list).
  3. Type the value next to it and save — it writes immediately.

7.3 Design value vs. actual value

Each parameter can hold both a "design" and an "actual" reading at once, each with its own value, unit, and description — useful whenever you need to check a design requirement against a real-world measurement (e.g. equipment acceptance testing).

7.4 Extracting automatically from a document's text

Once a document has been through Chapter 6's text recognition, DMS can search that text for your field names and pull out the numbers that follow, instead of you typing each one by hand.

  1. In the text-recognition panel, click "Extract key parameters".
  2. Check the field names you want extracted.
  3. Click "Start extraction" — DMS searches the full text for each field's keyword and the value that follows it.
  4. Review the results — each match is automatically split into value, unit, and description rather than one raw blob of text; a field that appears more than once in the document is captured as separate, numbered results ("Pressure_01", "Pressure_02", ...) so nothing is missed.
  5. Click "Apply to document" once it looks right.
Tip for tables Check "Same-line only" so DMS only matches content on the same line as the field name — ideal for tabular documents; leave it unchecked to search the whole text instead.

7.5 The preview flyout while checking values

While entering or double-checking a parameter by hand, you can pop open a draggable, freely-resizable preview of the source document, so you can look at the original text while you type — no more tabbing back and forth.

7.6 Exporting all metadata as a spreadsheet

Click "Project" → "Export Metadata (CSV)" to export every document's full set of key parameters as a spreadsheet, ready to open directly in Excel for review or further analysis.

08

AI Assistance (Optional)

Everything in this chapter is optional — leaving it unconfigured doesn't affect anything else in the app. It requires an API key of your own from an AI service (free or low-cost) and an internet connection. DMS now supports two AI providers: Google's Gemini and DeepSeek (faster and steadier for users in mainland China). Set up one or both, and switch between them anytime.

8.1 Getting and configuring a key

  1. Click "Project" → "AI-assisted extraction settings" to open the "AI provider settings" dialog.
  2. Gemini: click "Don't have an API Key? Get one for free at Google AI Studio" — aistudio.google.com/apikey. Sign in with a Google account, create a key, then copy and paste it into DMS.
  3. DeepSeek: click "Don't have an API Key? Get one at the DeepSeek platform" and repeat the same steps.
  4. Once saved, the key is encrypted at rest — never stored as plain text.
On cost Gemini's free tier processes up to 3 pages of a document at a time — plenty for most medical reports or product test reports. For documents running dozens or even hundreds of pages, a Gemini paid subscription (about $10/month) lifts that limit; the paid tier also comes with Google's commitment not to use your uploaded files to train its models, which matters for anything privacy- or business-sensitive.

8.2 AI-assisted key parameter extraction

For documents with a complicated layout that plain text matching can't handle (values scattered across charts or complex tables), let AI read the actual page image instead of just matching text. In the extraction panel from Section 7.4, check "Use AI" before starting extraction.

8.3 Asking AI across the whole project

  1. Switch to the top "Search" tab and click "Ask AI".
  2. Type a plain-language question, e.g. "What is the equipment's working pressure?"
  3. Pick Gemini or DeepSeek and ask — AI searches across every document and cites exactly which one each answer came from, so you can verify the source.

You can also scope the question to just one folder (check "This node and its subfolders only") instead of the entire project.

8.4 Q&A history saved automatically

Every question you ask and every answer AI gives is automatically appended to a running PDF log tied to that document — always available to reopen from the document list, and fully searchable, with nothing extra to organize yourself.

8.5 Package as a PDF for ChatGPT or other AI tools

The built-in "Ask AI" (Section 8.3) is great for quick lookups, but if you want to turn a set of photos and a story into a video, an article, or some other creative output DMS doesn't produce itself, use "Build PDF" instead — it packages your material for an external, file-upload-capable, vision-aware AI tool like ChatGPT to do the rest.

  1. In the "Ask AI about this folder" dialog (same entry point as Section 8.3), check the photos or documents you want to use.
  2. Type your request to the AI in the question box (e.g. "make a video from these photos and this story, with soft background music") — or dictate it and have AI organize/polish it first (Section 4.5).
  3. Click "Build PDF (for ChatGPT etc.)". DMS compresses the selected photos into a small but sharp PDF and bundles your written request in alongside them, then downloads the result.
  4. Upload that PDF to ChatGPT or another AI tool and make your request there as usual. Since the photos are already a lightweight PDF, uploading and processing stays smooth even with a large batch selected.
How this differs from Section 8.3 "Ask AI now" in 8.3 calls Gemini/DeepSeek directly, inside DMS, for a text answer. "Build PDF" here instead hands your material to an external AI tool of your choice — better suited to creative tasks DMS itself doesn't generate, like video or long-form writing.

Trend Charts

If a key parameter (like "Cholesterol", "Account Balance", or "Working Pressure") repeats across several documents in the same folder, DMS can plot it against date automatically — no need to export to Excel and chart it by hand.

9.1 Generating a chart

  1. Select the folder you want to analyze in the left tree.
  2. Click the "Plot" button in the toolbar above the tree.
  3. Pick the key-parameter field to plot, and whether to include all subfolders.
  4. DMS plots that parameter's value from every document against date, as a line chart. Dates come first from each document's own detected or entered date; if a document has none, DMS falls back to the "YYYY-MM" folder it's filed under.

Click any plotted point, or a row in the table below it, to jump straight to the source document — a quick way to double-check where a number actually came from.

9.2 Adjusting the chart window

  • Drag the chart window's header to move it, or drag an edge/corner to resize it.
  • Click "Pop out" to open the chart in its own separate browser window — handy for dragging onto a second monitor.
  • Both the time axis and value axis can be toggled between Auto and Custom range; switching to Custom starts from the current auto-fit range and updates live as you edit it.

9.3 Annualized return (for tracking balances and investments)

Pick any point on the chart as a "baseline" to see every other point's annualized return relative to it; you can also view the chained, point-to-point annualized return between neighboring points. Especially useful when tracking an account balance or investment performance over time.

9.4 Excel snapshot history (for hand-tracked totals)

Some numbers — like a total bank balance — don't come from any single document; they're a running total you check and record yourself from time to time. That's what "snapshots" are for:

  1. Click "Save snapshot" in the chart window to append today's date and value to a per-folder, per-parameter Excel history file.
  2. Switch to the "Total vs. time" view to read that history straight back into a chart — no extraction from any single document needed.

9.5 AI trend commentary (optional)

If AI is already configured (Chapter 8), click to enable an AI read on the trend's direction, its approximate rate of change, and any outliers worth a second look.

Photos & Face Recognition

10.1 Setting a photo root folder

First designate one folder as your photo library's root — every automatically-organized photo from then on lands somewhere under it.

  1. Right-click the folder you want as the root (e.g. create a new folder called "Photos").
  2. Choose "Set as photo root folder".
  3. Its icon changes to a camera icon, confirming it's set. To undo this, right-click and choose "Unset photo root folder".
Note Only one photo root is allowed per project.

10.2 Uploading photos

Uploading a photo into the photo root (or one of its subfolders) makes DMS automatically read its capture date (EXIF data) and create the matching "year/month" subfolders under the root to file it into. If the photo carries GPS data, the shooting location is picked up too, shown as a "Location" metadata field with a one-click link to view it on a map.

10.3 Tagging a face

  1. Select one or more photos.
  2. Click "Tag faces", draw a box around a person in the photo, and type their name (the first time you tag someone, a new "person" entry is created; reuse the same name afterward to group photos under that same person).

10.4 Browsing photos by person

  1. Switch to the top "Faces" tab.
  2. Click any tagged person to see every photo of them across the whole library.
  3. Click "Auto-scan for matches" to search a folder or the entire library for more photos of that person (or everyone), with an adjustable match-confidence threshold.

To remove someone, delete the person and every one of their tags in a single action — the photos themselves are untouched. The first time you use face recognition, DMS guides you through installing the underlying engine, with live progress shown.

10.5 Finding near-duplicate photos

Burst shots, repeated saves, or re-exports often leave several nearly-identical copies of the same photo scattered through a batch. DMS can automatically find these "near-duplicates" and recommend which one to keep.

  1. Open a folder containing photos and click "Find near-duplicates" next to the "Select" button in the toolbar to enter photo-selection mode.
  2. Check the photos you want to compare (only image files can be selected), and set the similarity threshold on the right (defaults to 75% — higher means a stricter match).
  3. Click "Check selected". DMS compares every pair of the checked photos and groups the ones that meet the threshold together, showing each group's lowest pairwise similarity.
  4. Within each group, DMS marks the photo with the highest resolution and largest file size (usually the least-compressed, best-quality copy) with a ★ badge as the suggested keeper — the final call is still yours.
  5. When you're happy with the groups, click "Mark for review". DMS links (not moves) each group's photos into a new "Group N" subfolder under a "Suspected duplicates" folder at the root, leaving the originals exactly where they were, so you can review, compare, and delete at your own pace.
Thumbnail size Both the results dialog and the normal grid view offer a "Small"/"Large" thumbnail toggle for closer comparison — your choice is remembered for next time (see Section 5.7).
Deleting inside "Suspected duplicates" is what actually cleans up Photos in this review folder are only linked there — the originals still live in their own folders, and by the general rule in Section 5.6, deleting elsewhere normally just removes that one reference. But deleting a photo directly from inside "Suspected duplicates / Group N" removes it from every location it's linked to, including the original folder, and moves it into the "Not Show in Tree" recycle folder — which is what actually frees up space and cleans up the duplicate.

Generating a Databook (Bound PDF Package)

The "Data book" feature merges any set of documents you select from the folder tree into one formal PDF, complete with a cover page, table of contents, and per-section bookmarks — ideal as a handoff package or for archival printing.

  1. Switch to the top "Data book" tab.
  2. Check the documents to merge in the document picker — you can select across multiple folders.
  3. Fill in a title and subtitle for the databook (optionally insert your own cover page ahead of the auto-generated one).
  4. Click "Generate and download" — DMS arranges everything into a section structure following folder order and serial numbers, then merges it into one PDF.
  • Image-only folders convert automatically into print-ready PDF pages.
  • A landscape source page rotates automatically to portrait, so the whole book stays consistently oriented.
  • With many photos involved, images are intelligently re-compressed before embedding — near-invisible on the page, but the whole file can shrink to roughly one-hundredth of its original size.
Tip Your selection and title are remembered automatically after you generate once, so reopening the "Data book" tab next time picks up right where you left off.

Sharing Documents

12.1 Sending by email

Set up an SMTP mail account once first (works the same on Mac and Windows):

  1. Click "Project" → "Email sending settings".
  2. Click the quick-select button for your provider (Gmail / Yahoo / Outlook / iCloud / QQ Mail / 163) to auto-fill the server address and port.
  3. Fill in your username (your email address) and password. Gmail users must use an "App Password", not their normal account password — generate one separately in Google Account settings.
  4. Click "Send test email" to verify — a test message should arrive in your inbox. Once confirmed, click "Save settings".

Once set up, to send a document:

  1. Click the email icon on a document's card.
  2. Fill in the recipient's address (DMS remembers the last one you used), a subject (defaults to the document's name), and an optional message body.
  3. Click "Send email" — it goes out directly over SMTP and typically arrives within moments.
Without SMTP configured On Mac, DMS falls back to opening a draft in the Messages or Mail app for you; on Windows, SMTP must be configured first before you can send an email at all.

12.2 Send to phone

Click the phone icon on a document's card, enter the recipient's phone number, and click send. DMS generates a download link valid for one hour and sends it via the Mac Messages app (iMessage/SMS) or the Windows "Phone Link" app — the recipient needs no DMS-related app at all, just tap the link to download.

Mobile & Remote Access

This chapter covers the reverse direction — sending photos or files from your phone into DMS, or browsing your computer's whole folder tree straight from your phone. Both are driven from the small status window that appears at launch (the "QCDMS" window from Section 1.2), not from the browser page itself.

13.1 Uploading photos or files from your phone into a folder

  1. On your computer, find that small status window (check your taskbar/Dock if it's minimized) and click "Remote Upload".
  2. In the dialog, optionally enter a phone number (with country code, e.g. +16505551234), and pick which folder incoming files should land in from the dropdown.
  3. Click "Generate Link" — DMS starts a secure public tunnel and produces a QR code and URL (this usually takes a few seconds to around ten).
  4. Scan the QR code with your phone, or click "Send via iMessage / SMS / WeChat" to text the link directly — or "Copy URL" to send it manually.
  5. Opening the link on the phone lets you take a photo or pick one from the camera roll and upload it straight away — it lands in the folder you chose in step 2.
Link expiry This remote upload link is valid for 7 days. After it expires, click "Generate Link" again to make a new one.

13.2 Browsing your computer's files from your phone

Opening the same link from Section 13.1 on your phone shows a "Browse" option on the page — tap it to browse the whole folder tree and open documents just as you would on the computer, not just upload new ones.

13.3 Local access on the same Wi-Fi

If your phone and computer share the same Wi-Fi network, you can skip the public tunnel entirely and open your computer's local network address in the phone's browser (something like http://192.168.x.x:port/mobile) to reach the same upload page. If you're not sure of your computer's local address, the "Remote Upload" flow from 13.1 is the simplest option since it works on any network.

Backup, Export & Import

Everything in DMS is ordinary files — nothing is locked into a proprietary format. Click the "Project" button at the top to see every backup/export option.

14.1 Three ways to export

Export index backup (.dms)Saves just the folder tree structure and metadata — no actual files. Filenames start with METADATA-; small and fast, good for preserving structure quickly.
Export full backup (with files)Bundles the folder tree, metadata, and every actual document and photo together. Filenames start with COMP- — the most complete backup possible.
Export selected folders (with files)Check specific folders first, and export only their tree and files. Filenames start with PART- — good for sharing or backing up just part of the library.

There's also "Export Metadata (CSV)" — exports every document's metadata as a spreadsheet for review or bookkeeping in Excel.

Only the last 10 are kept Exported .dms backup files are saved inside the storage folder. The project folder keeps at most 10 .dms backups; older ones are automatically moved into the "Not Shown in The Tree" folder, so they never pile up indefinitely.
With a project password set If the current project has a project password (Section 15.2), every one of the above exports is automatically encrypted with it — there's no separate export password to set.

14.2 Importing a .dms backup

  1. Click "Project" → "Import project (.dms)", or drag a .dms file straight onto the upload area.
  2. Choose a destination folder to extract it into.
  3. Confirm — DMS extracts and imports, then automatically switches to the newly-imported project.

Import only restores the folder tree structure; it never deletes any existing files already on disk.

14.3 Starting a brand-new blank project

Click "Project" → "Create new blank project" and enter a new, empty folder path. The project you're currently using is unaffected, and you can switch back anytime using the storage path button at the top.

14.4 Free cloud backup

Point the storage path at a OneDrive or Dropbox folder that's already syncing, and every bit of DMS's data backs up to the cloud automatically along with that folder — no extra steps. A step-by-step OneDrive setup guide is available in-app (under "Downloads" in the Project menu).

One more reminder On Mac, don't put the storage path inside iCloud Drive (see Section 1.3).

Security & Passwords

DMS offers two completely independent layers of password protection — use just one, or both.

15.1 App login password (protects DMS on this whole machine)

An optional login password protecting the entire DMS application on this machine, regardless of which project is currently open — good for a shared computer, or whenever you want DMS unreachable by anyone without the password.

  1. Click "Project" → "Set app login password".
  2. Type a new password (twice to confirm) and save — it takes effect immediately. From then on, opening DMS in a browser requires this password first.
  3. To change or remove it, return to the same menu item (now shown as "Change or remove app login password"), verify your current password, and proceed — leave the new password blank to remove it entirely.
  4. Once a password is set, a "Log out" option appears in the menu — clicking it ends the current browser session, requiring the password again next time.
How it's stored The password is stored encrypted (SHA256 with a random salt, 100,000 iterations) in a local config file — never in plain text.

15.2 Project password (protects just one specific project)

A completely separate, second password that belongs to one specific project — it's stored inside that project's own folder, so it travels along whenever the folder is copied, synced, or handed off. It's required to open that project directly, or to import its exported .dms file anywhere else.

  1. Click "Project" → "Set project password".
  2. Optionally give the project a friendly name (shown on its lock screen and in the file picker), set a password, and save.
  3. Once set, a padlock-badged project name appears in the toolbar; a "Lock this project" option appears in the menu — clicking it requires the project password again to keep viewing (without affecting the app login above).

15.3 Storing website logins per folder

Save one or more sets of related website address, username, and password against a specific folder (e.g. a piece of equipment's manufacturer portal login) — decrypted only when you click "reveal". Any folder can now hold any number of these logins, with a "copy username" quick-action button included.

Frequently Asked Questions

I forgot the app login password — what do I do?
You can reset it by editing the local config file directly. It's located at ~/.pms_dms_config.json on Mac, or C:\Users\yourname\.pms_dms_config.json on Windows. Open it in a plain text editor and set both the password_hash and password_salt fields to an empty string "", save, and restart DMS — password protection is removed. (This is the app login password, distinct from Section 15.2's "project password", which lives inside the project's own folder — the same edit-and-clear approach works on its config file there.)
I accidentally deleted a folder or document — can I get it back?
Deleting a document only removes one reference as long as it's linked elsewhere — the file itself stays. Only once the last reference is deleted does the file move into the "Not Show in Tree" folder on disk, where you can find it manually. Deleting an entire folder, however, is not reversible — export a backup (Chapter 14) before doing anything important. If your storage path is inside a cloud-synced folder (like OneDrive), its version history may also help recover a deleted file.
Why does sending email show an "SMTP error"?
Common causes: Gmail without an "App Password" (using the regular account password instead); a provider's SMTP access isn't turned on (QQ Mail and 163 both require enabling it manually in their web interface first); or a company firewall blocking ports 587/465 — contact your network admin in that case.
Can documents be shared across multiple computers?
Yes. Point the storage path at a shared network drive, or a cloud-synced folder (OneDrive, Dropbox — avoid iCloud Drive on Mac, see Section 1.3), and every computer's DMS pointed at that same path shares the data. Just avoid editing the same document from two computers at the same time to prevent conflicts — dividing work by folder is the safest approach.
Windows says "Windows protected your PC" (SmartScreen) when I double-click DMS.exe — what now?
This happens because DMS.exe is a newly-built executable that hasn't been paid-certified with a digital signature from Microsoft — Windows blocks unrecognized new programs by default to protect users; it doesn't mean anything is wrong with it. Two ways around it:

Option 1 (recommended, simplest): on the warning screen, click the "More info" link — a "Run anyway" button appears at the bottom; click it to launch normally.

Option 2: if that window is already closed or unresponsive, right-click DMS.exe → "Properties" → check the "Unblock" checkbox near the bottom of the "General" tab → click "Apply" → "OK". This permanently clears the warning for that file going forward.
What file formats are supported?
PDF, JPG, JPEG, PNG, HEIC, TIFF, GIF, WEBP, and BMP for images, plus text formats like TXT and CSV. In principle any file type can be uploaded and stored, but in-browser preview is limited to the formats listed above — anything else can still be downloaded and opened with the matching application.
What's the difference between DMS.app and DMS.exe — are they just the Mac and Windows versions?
Exactly — they're functionally identical, just packaged executables for Mac and Windows respectively. Double-click to run; no separate Python install or dependencies needed.
